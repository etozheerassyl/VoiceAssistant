# MacMediaService — Фоновый сервис медиаданных, громкости и спектрального аудиоэквалайзера macOS

Сервис обеспечивает двусторонний обмен данными между MacBook Air M1 и платой ESP32-S3 с горизонтальным дисплеем ILI9341 (320×240) через локальную сеть Wi-Fi по протоколу TCP/JSON.

## Архитектура и возможности

1. **Реактивный 16-полосный спектральный анализатор аудио (`audio_analyzer.swift` & `audio_processor.py`)**:
   - Захватывает системный аудиопоток macOS через нативный фреймворк **ScreenCaptureKit** (`SCStreamOutputType.audio`, 48000 Гц, 2 канала) без изменения устройства вывода звука и без использования микрофона.
   - Выполняет преобразование стерео в моно, оконное взвешивание Ханна и 2048-точечное БПФ (Radix-2 FFT через Apple `Accelerate / vDSP`) в выделенном фоновом потоке.
   - Вычисляет уровни **16 логарифмически распределённых частотных диапазонов** (25 Гц – 16 кГц) с перцептивной компенсацией наклона спектра, защитой от клиппинга/NaN и асимметричным сглаживанием (быстрая атака / плавное затухание).
   - Передаёт компактные сообщения `{"type": "equalizer", "bands": [...], "state": "playing"}` с частотой до 30 кадров/с.

2. **Системный медиа-источник (`media_helper.swift` — MediaRemote & CoreAudio)**:
   - Автоматически считывает статус воспроизведения из macOS Control Center / Now Playing (Яндекс Музыка, YouTube, Apple Music, Spotify в Safari/Chrome).
   - Изменяет и считывает **системную громкость macOS** с точностью до 1% без задержек.
   - Поддерживает системные команды: `PLAY_PAUSE`, `NEXT_TRACK`, `PREVIOUS_TRACK`, `SEEK_TO`, `SEEK_FORWARD`, `SEEK_BACKWARD`, `SET_VOLUME`.

3. **Браузерный мост для YouTube (HTTP Bridge)**:
   - Локальный HTTP-эндпоинт (`http://127.0.0.1:8766/api/browser_update`) принимает точные данные из плеера YouTube.
   - Диагностический эндпоинт `http://127.0.0.1:8766/api/status` отображает текущее состояние плеера и спектра эквалайзера.

4. **Сетевой сервер для ESP32 (`server.py`)**:
   - TCP сокет на порту `8765` с включённым `TCP_NODELAY`.
   - Потокобезопасная трансляция `media_state` и `equalizer` в формате JSON Lines (`\n`).
   - Автоматический переход в экономичный режим при паузе или тишине.

## Быстрый запуск

### 1. Разрешение macOS для захвата системного звука (один раз):
```bash
cd MacMediaService
./request_audio_permission.sh
```
В открывшемся окне **Системные настройки → Конфиденциальность и безопасность → Запись экрана и системного аудио** включите переключатель для вашего приложения терминала.

### 2. Запуск сервиса на MacBook:
```bash
cd MacMediaService
./start_service.sh
```

### 3. Проверка DSP и сетевого обмена:
```bash
./audio_analyzer --self-test
python3 test_client.py
```

### 4. Остановка сервиса:
```bash
./stop_service.sh
```
